# AQ26 External Review Protocol

An external reviewer receives the exact immutable review pack, release receipt and code commit that are proposed for publication. Review is recorded against six domains: data provenance; measurement and QA/QC; statistical method; spatial/meteorological reasoning; claims and uncertainty; and public communication/accessibility.

Reviewer outcomes are: approve; approve with bounded wording; revise and resubmit; or reject. Each finding has an identifier, severity, evidence location, requested change, response, test and closure record. Reviewer names and affiliations are published only with consent. AQ26 must never imply WHO, regulator, university or named-expert approval without a retained approval record for the exact release.
