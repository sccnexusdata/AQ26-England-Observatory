# AQ26 England Air Quality Observatory

**Public evidence, methodology and reproducibility surface for an independent England-wide air-quality and environmental evidence observatory.**

AQ26 combines official monitoring observations with meteorological, emissions, satellite, modelled and contextual evidence. The public repository is a governed output of a separate private scientific engine: only material that passes AQ26 public-release and export checks is copied here.

## Scientific boundary

AQ26 is an evidence-screening and descriptive environmental observatory. A monitoring observation, model output, satellite product, traffic record, permit document or other single source does **not** by itself establish source attribution, causation, individual exposure, health effect, permit breach or legal non-compliance.

A zero screening result means only that no eligible assessment crossed the declared screening criteria for that release. It must not be interpreted as proof of clean air or absence of pollution.

## What this repository contains

- `site/` — the reviewed public website generated by the governed AQ26 release.
- `data/latest/` — selected public-safe machine-readable release summaries.
- `reports/latest/` — public scientific appraisal material where available.
- `provenance/` — reproducibility/runtime receipts approved for public release.
- `PUBLIC_RELEASE_MANIFEST.json` — SHA-256 manifest for every exported file, including the originating governed source commit where available.

## What this repository deliberately does not contain

The private scientific engine, credentials, secrets, protected/test builds, provider-restricted raw data, internal forensic logs, deployment configuration and unpublished review material are not mirrored here.

## Provenance and reproducibility

Every automated export is allowlisted. The public manifest records file hashes and release provenance so that changes can be audited over time. Public outputs should be interpreted together with their stated coverage, freshness, quality status, units and methodological limitations.

## Data licensing

AQ26 does not claim ownership of third-party observations or datasets. Source-specific licences and reuse conditions continue to apply. Public redistribution is limited to material for which AQ26 has an appropriate publication basis or to derived summaries that preserve source attribution and limitations.

## Independent scrutiny

Questions, methodological critique, reproducibility checks and evidence-based corrections are welcome. Proposed changes to scientific interpretation should identify the relevant source, time period, units, quality state and supporting evidence rather than relying on proximity or temporal coincidence alone.
